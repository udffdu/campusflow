# 环境与交付配置

当前无服务器、云资源或已生效的部署配置。

- 讨论候选：Docker Compose；开发、测试、生产的数据库、配置和凭据隔离。
- 华为云规格、系统版本、网络与预算待确认；不在预备阶段采购。
- 后续编排覆盖 web、D、M1、M2、M3 和数据库，具备健康检查、持久化和备份。
- 构建在 CI 完成；测试自动部署整套版本，生产人工批准后部署同一制品。
- 按环境串行部署，协调部署窗口；迁移失败时停止发布。
- 数据库账号按模块限制权限，迁移历史分开维护；空库可重建，种子数据可重复执行。
- 回退优先使用兼容旧版本的 schema；破坏性迁移另定恢复方案并验证备份。

真实配置接入时必须增加实际构建、迁移、部署与回退验证；不建立永远成功的占位部署任务。
