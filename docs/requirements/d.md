## 验收与边界

- 本地账号登录、退出、密码修改；管理员管理账号及角色。密码 BCrypt，随机会话只存哈希；停用与角色变更下一请求生效。
- RBAC 角色为管理员、空间管理员、审计员、普通成员。管理员全局操作；空间管理员只能修改本院系教室/座位；审计员只能查询本院系审计。读取空间目录对已登录成员开放。
- 校区→楼栋→教室→座位使用稳定 UUID。支持属性、教室每周开放时段、停用及版本冲突检测；无硬删除，不维护预约/维修状态。父级停用使子级有效状态停用，原记录仍可查询。
- M1/M2/M3 使用不同服务凭据读取主数据、在线验证用户会话和接收通知/审计。服务来源由凭据决定，不能由请求体指定。未配置凭据即关闭该服务访问。
- 通知采用真实站内信渠道：事件先持久化为投递任务，后台原子写入收件箱；按来源、事件、收件人去重，载荷不同返回冲突。失败指数退避，五次后进入失败队列，管理员可重试。前端可查阅和标记已读。
- 审计不可修改/删除，保存来源、操作者、院系、动作、对象、结果、请求编号和时间。接入事件只允许结构化理由码，不接收任意日志或密码/令牌等字段。
- Vue 3 前端包括登录、概览、资源目录/维护、账号角色、通知中心、投递任务、审计查询；具备空态、错误、加载和权限反馈。M1/M2/M3 页面由对应模块后续实现。

## 实现决策

- Spring Boot 3.5、Java 21、Spring JDBC、Flyway、PostgreSQL；Vue 3 + TypeScript + Vite，原生 CSS，无外部字体或运行时 CDN。
- 浏览器使用 HttpOnly/SameSite=Lax 会话 Cookie，写操作同时要求 Spring Security CSRF 令牌。生产必须 HTTPS 并打开 secure cookie。内部服务接口使用独立 Bearer 密钥，不允许浏览器跨域携带凭据。
- 会话有效期 8 小时，权限实时读取；五次失败登录锁定五分钟。初始化管理员密码只从环境变量读取，仓库没有可用默认密码。
- 数据范围按院系，资源不允许变更类型、父节点或院系；迁移归属需另立业务方案，避免破坏其他模块历史引用。
- 用户与资源列表分页；内部读取停用资源用于历史展示，新业务必须检查 effectiveActive 与版本，再由 M1 原子判断占用。
- 审计与 D 本地业务同事务；业务模块自行使用 outbox 重试发送事件。D 不为尚未收到的跨模块事件提供可靠性承诺。
