## 1. 怎么使用这份确认单

- A＝你，已确认负责故障上报与派单；B＝另一位 M3 同学。B 的具体工作及公共工程分工仍请双方确认。
- 决策表中的“二人”表示模块内部方案；“外部”表示你们先达成提案，还需 D/M1/全组相关负责人评审，不能由两人直接宣布生效。
- 任务书和 AGENTS.md 已有的要求直接遵守，不以投票取消；讨论的是如何落实。
- 每一项在末尾的决策记录中填“采用推荐 / 修改后采用 / 延后”，写明修改内容和依据。关键阻塞项未决时，不让 AI 自行补齐规则。
- 推荐讨论顺序：分工与首轮范围 → 上报/查询/派单 → 状态与后续功能 → 接口架构 → 工程与 AI → 风险 → 汇报材料。
