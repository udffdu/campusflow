## 修复

- `ReminderStore.scheduleDue` 在 LIMIT 前按预约和事件类型排除已有事件，保留数据库唯一约束与 SKIP LOCKED。连续小批次不再反复选中同一批预约。
- D V6 添加邮件 claim_token；每次领取更换令牌，发送前与回写均检查令牌、DELIVERING 状态及有效租约。手工 retry 重置尝试数不影响领取身份隔离。
- M1 提醒 outbox 同类风险一并修复：不重置的 attempts 作为领取代数，过期或被接管的旧任务不能准备发送、成功回写或安排重试。
- M2 的身份字段兼容与 V2.1 升级策略在 [PR #4](https://github.com/udffdu/campusflow/pull/4) 中修复。
