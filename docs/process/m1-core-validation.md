## 运行方法

在配置好 Java 21 的仓库根目录执行：

```sh
./services/platform/mvnw -B -f services/seats/pom.xml verify
```

本阶段复用仓库已有 Maven Wrapper 与锁定的 Maven 版本，仅构建 seats 模块，不修改或启动 platform。依赖使用现有 Spring Boot 3.5.16 父 POM 管理的 JUnit；核心没有 Spring 运行时依赖。

## 验证内容

- 非空正区间、相交、包含、相邻及分离区间。
- 五种状态结合实际时段的阻挡/释放语义，不测试虚假的状态转换完成。
- 整点、过去时刻、可配置提前窗口和时长、上海时区、纳秒边界。
- 测试时使用24小时参数的用例验证滚动窗口具体化建议，不代表最终配置管理机制已完成。
- 独立副本删除窗口拒绝逻辑、破坏相邻区间判断后，对应测试必须失败；不修改正式源码进行破坏实验。
